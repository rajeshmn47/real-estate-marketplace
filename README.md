## Overview

Open Property Platform is a full-stack real estate marketplace inspired by modern property platforms.

Buy, rent, sell, lease, and discover properties through an intuitive map-first experience powered by AI, geospatial intelligence, and rich property data.

This project is designed for developers who want to learn how to build production-grade marketplace applications.
